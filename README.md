# DUBBE

### AI-Powered Video Translation & Dubbing

**DUBBE** is an AI-powered pipeline for automatically translating and dubbing educational and training videos into another language.

The system combines speech recognition, machine translation, text-to-speech synthesis, and audio-video synchronization to transform a source video into a watchable dubbed version.

Beyond generating the final video, DUBBE evaluates how errors propagate through the pipeline and identifies where the quality of automated dubbing breaks down.

**Pipeline:**
`Video → ASR → Sentence Segmentation → Translation → TTS → Timing → Dubbed Video`
